# 诡秘之主俱乐部管理平台须知 · 共享版

这是一份**可自建的工会管理工具源码**：成员档案、总览统计、DKP 考勤、论坛分享。

拿到本包后，请把它改成**你自己工会**的平台——改名称、改管理员账号、（可选）接自己的对象存储。  
包内不含任何现成工会的业务数据或密钥。

---

## 你需要准备什么

- 一台能跑 Python 3 的电脑（Mac / Windows / Linux 均可）
- （可选）若论坛要发图/视频：腾讯云 COS 存储桶与 API 密钥

---

## 1. 设置管理员账号密码

```bash
cp .env.example .env
```

编辑 `.env`：

```bash
ADMIN_USER=你的管理员用户名
ADMIN_PASSWORD=请换成足够强的密码
PORT=8765
```

也可用环境变量临时覆盖，不必写进文件。

> 模板里的示例密码仅供本机试用，给成员用之前务必改掉。

---

## 2. 启动网页

```bash
./start.sh
```

浏览器打开：[http://127.0.0.1:8765/](http://127.0.0.1:8765/)

| 身份 | 能力 |
| --- | --- |
| 访客 | 可看总览、DKP、论坛；**不能**看成员档案 |
| 管理员 | 登录后可查看/编辑档案、考勤、删帖、导入导出等 |

首次运行会自动创建 `data/club.db`（SQLite）。这是你自己的数据，请自行备份。

---

## 3. 改成你自己的品牌

前端与文案里默认写的是「我的工会」一类占位名。请按喜好修改，例如：

- `index.html` 标题、侧栏品牌名
- `js/app.js` / `js/data.js` 中的显示文案
- `server.py` / `start.sh` 中的默认管理员名（仍建议以 `.env` 为准）

改完刷新页面即可，无需复杂构建步骤。

---

## 4. 论坛图片 / 视频（可选）

不配置也能发**纯文字**帖。要发图/视频时：

1. 腾讯云开通 COS，创建存储桶  
2. 创建 API 密钥（SecretId / SecretKey）  
3. 填入 `.env`（字段见 `.env.example`）  
4. 重启 `./start.sh`

发帖时由服务端签发短时上传凭证，浏览器直传 COS。

---

## 5. 让工会成员在公网打开（可选）

本机 `127.0.0.1` 只有你自己的电脑能访问。若要给外地成员用，任选其一：

| 方式 | 费用 | 说明 |
| --- | --- | --- |
| 临时公网隧道 `./public.sh` | 通常免费 | 电脑需开机且服务在跑；**每次重启链接可能变化**，适合临时试用 |
| Render 等免费托管 | 通常免费 | 有固定网址，但免费实例会休眠、海外访问可能偏慢，SQLite 持久化需留意 |
| 云服务器长期部署 | 需付费 | 链接固定、最稳，适合正式长期使用 |

日常固定入口更推荐「能常开的主机 + 固定地址」；临时隧道不适合当作唯一长期入口。

---

## 6. 数据备份

系统设置页可导出 / 导入 JSON。换电脑或重装前请先导出备份。

---

## 目录说明

| 路径 | 作用 |
| --- | --- |
| `server.py` | HTTP API + 静态站点 |
| `cos_util.py` | 腾讯云 COS 辅助 |
| `index.html` / `css/` / `js/` | 前端 |
| `start.sh` / `public.sh` | 启动与临时隧道 |
| `.env.example` | 环境变量模板（复制为 `.env` 后填写） |

**请勿**把填好的 `.env` 或 `data/` 目录再分享给别人。
